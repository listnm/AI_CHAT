Grok OAuth 账号

导入 Sub2API/grokcli 导出的 JSON，凭据只加密保存在服务器，不会在页面返回完整 token。

Grok OAuth 授权

按 Sub2API 的 PKCE 流程跳转到 x.ai 授权，回调后自动加密保存 access_token 与 refresh_token。不会在页面显示 token。

授权地址：auth.x.ai/oauth2/authorize
Token 地址：auth.x.ai/oauth2/token
回调地址：当前域名/api/grok/oauth/callback

兼容导入

也支持顶层包含 accounts 数组且 platform=grok 的导出文件。导入后会清空输入内容。

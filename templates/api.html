导入账号 JSON

支持顶层包含 accounts 数组且 platform=grok 的导出文件。导入后会清空输入内容；请勿把 token 粘贴到聊天或公开位置。

调用说明

Grok OAuth 账号导入后仅用于账号状态管理与连接测试。当前页面不会自动把它接入现有 OpenAI/Anthropic 转发，避免在未确认 Grok 协议时误转发。

敏感字段

access_token、refresh_token、client_id 只加密保存；列表只显示是否存在、过期时间和脱敏邮箱。刷新 OAuth 暂未配置，需重新导入最新 JSON。

来源格式

这是账号凭据导入，不是 Sub2API 的 redeem code/余额兑换接口。
